# Comedor Universitario UNAMBA

Sistema de gestión del comedor universitario (caso práctico de control de versiones con Git y GitHub).

## Módulos
- `config.py`   Parámetros generales
- `menu.py`     Menú del día (RF03)
- `reservas.py` Reservas y control de aforo
- `pagos.py`    Pagos y ticket (RF06, RF07)
- `reportes.py` Reportes diarios (RF11)

## Versiones
v1.0 Estructura base | v2.0 Menú | v3.0 Reservas y aforo | v4.0 Pagos y ticket | v5.0 Reportes
